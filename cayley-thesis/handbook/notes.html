從 Cayley graph 到 Cayley surface：統一數學筆記

這份筆記只陳述目前程式真正能重建與驗證的數學物件。資料單位不是一張圖，而是 $(G,S,\mathcal F,c,\omega)$：有限群、對稱生成集、面系統、可重建面系統的 witness， 以及可選的正 edge weights。catalogue 保存 $c$；未做不對稱實驗時 $\omega\equiv1$。

目錄 1. Cayley graph 與兩種乘法 2. Darts、rotation system 與面 3. 曲面條件、Euler characteristic 與 genus 4. 搜尋範圍與「所有面系統」的限制 5. 一般 Laplacian 與表示論 6. 離散 Hodge Laplacian 7. 已驗證 catalogue 8. Spectral clustering 與不對稱性 9. 三個對外數學問題

1. Cayley graph 與兩種乘法

定義 1.1（Cayley graph）
令 $G$ 為有限群，$S\subset G$ 滿足 $S=S^{-1}$、$e\notin S$，並假設 $S$ 生成 $G$。 $\Gamma=\operatorname{Cay}(G,S)$ 的頂點是 $G$，無向邊是 $\{\{g,gs\}:g\in G,s\in S\}$。因此 $$V=|G|,\qquad E=\frac{|G||S|}{2}.$$
兩種乘法的工作不同
右乘 $g\mapsto gs$ 用來沿生成元標記走邊；字 $s_1\cdots s_k$ 產生路徑 $g,gs_1,\ldots,gs_1\cdots s_k$。左乘 $g\mapsto hg$ 則保存生成元標記， 把整張圖、路徑或面平移。左乘是 vertex-transitive graph automorphism， 因為 $h(gs)=(hg)s$。
重要限制
關係式 $s_1\cdots s_k=e$ 只保證路徑閉合，不保證路徑為 simple cycle， 也不保證一批 relator cycles 能覆蓋每一條 dart 恰好一次。因此「找關係式」是候選面生成法， 不是所有面系統的標準枚舉法。

2. Darts、rotation system 與面

定義 2.1（dart 與 reversal）
dart 是 $(g,s)\in D:=G\times S$，表示 $g\to gs$。反向 involution 為 $$\alpha(g,s)=(gs,s^{-1}).$$ 每條無向邊正好對應兩條 darts，所以 $|D|=2E$。
定義 2.2（orientable rotation system）
在每一個頂點 $g$ 選擇離開該點之 darts 的一個 cyclic order。把所有局部 cyclic orders 合併成 permutation $\sigma$。則 face permutation 定義為 $$\varphi=\sigma\alpha.$$ $\varphi$ 的 cycles 就是嵌入的有向面邊界。對 connected graph 而言，一個 rotation system 決定一個 closed orientable cellular embedding。
為何 rotation system 比 dart 清單可靠
只檢查每條 dart 被某個 cycle 使用一次，仍可能在頂點產生多個 link circles， 把同一頂點夾成 pinch point。rotation system 直接規定每個頂點只有一個 cyclic order； 若從任意 face list 反推曲面，仍必須額外檢查每個 vertex link 是單一圓。
群對稱與面的方向
左乘必須保存無向面集合；它不一定保存每一個面的已選方向。左乘可能把某面送到另一個面， 也可能送到同一無向面的反向。因此 catalogue 對 face cycle 的 canonicalization 同時商掉 cyclic shift 與 reversal，不把「directed orbit invariant」誤當必要條件。

3. 曲面條件、Euler characteristic 與 genus

驗證條件 3.1
一個 catalogue witness 被接受為 closed orientable Cayley surface 前，驗證器依序檢查：
  1. $S=S^{-1}$、$e\notin S$，而且 Cayley graph connected；
  2. 每個 face 是 simple cycle；
  3. 所有 faces 的 darts 恰好等於 $G\times S$，無遺漏也無重複；
  4. 每個頂點的 face corners 形成一個 vertex-link cycle；
  5. $\chi=V-E+F$ 給出非負整數 genus $g=1-\chi/2$。
定理 3.2（Euler genus）
若以上條件成立，所得 cell complex 是 connected closed orientable surface，且 $$\chi=|G|-\frac{|G||S|}{2}+|\mathcal F|=2-2g.$$ 因此同一 $(G,S)$ 可因 $|\mathcal F|$ 或 face incidence 不同而得到不同 genus。
例 3.3（$D_4$ 的 topological switching）
固定 $D_4=\langle r,s\mid r^4=s^2=e,\ srs=r^{-1}\rangle$ 與 $S=\{r,r^{-1},s\}$，故 $V=8,E=12$：
  • 6 個 squares：$\chi=8-12+6=2$，$g=0$；
  • 4 個 hexagons：$\chi=8-12+4=0$，$g=1$；
  • 2 個 squares 加 2 個 octagons：仍有 $F=4$，$g=1$，但 face profile 不同。
骨架與 adjacency spectrum 固定，曲面資料則不同。

4. 搜尋範圍與「所有面系統」的限制

不存在一個對任意有限群都廉價地列出所有面系統的單一步驟。正確的通用對象是 rotation systems，但候選數目隨 degree 與 $|G|$ 指數成長。若 $d=|S|$，固定頂點標記後， 一般 local rotation search 約有

$$((d-1)!)^{|G|}$$

個候選，還未除以 graph automorphisms 或 orientation reversal。

建構法真正覆蓋的範圍是否完整
relator orbits由指定關係字與其左平移生成的面否
uniform rotation所有頂點使用相同 generator cyclic order只對 uniform subclass 完整
local binary rotation三正則圖每頂點的兩種方向，共 $2^{|G|}$對固定 cubic skeleton 的 orientable rotations 完整，尚未商 automorphisms
general local rotation每頂點任意 cyclic order概念上完整，但通常不可直接暴力枚舉
explicit rotation保存一個可重建的具體 witness不是搜尋法
目前的完備性聲明
catalogue 證明「這 25 個 witness 都有效」，不證明「每個 $(G,S)$ 的所有非同構面系統都已找到」。 若兩個 witness 有相同 genus 與 face profile，仍需計算 graph automorphism 對 rotation systems 的作用，才能判斷它們是否真為不同 embedding。這是目前 V3 驗證層。

5. 一般 Laplacian 與表示論

定義 5.1
若 $A$ 是 Cayley graph adjacency matrix，$d=|S|$，則 $L_0=dI-A$。因 $A$ 與 left regular action commute，在有限群 Fourier decomposition 下， 每個 irreducible representation $\rho$ 對應小矩陣 $$A_\rho=\sum_{s\in S}\rho(s).$$ $A_\rho$ 的每個 eigenvalue 在 regular representation 中重複 $\dim\rho$ 次。
Spectral blindness
$A$ 與 $L_0$ 只依賴 $(G,S)$，完全不讀取 $\mathcal F$。因此 $D_4$ sphere 與 torus 擁有相同 vertex spectrum。一般 graph eigenvalues 可以描述骨架對稱、expansion 與 cut， 卻不能單獨恢復所選曲面的 genus。

6. 離散 Hodge Laplacian

定義 6.1（cellular boundary 與 $\Delta_1$）
固定每條 edge 與 face 的方向。令 $B_1:C_1\to C_0$ 為 vertex-edge incidence， $B_2:C_2\to C_1$ 為 edge-face incidence。首先必須有 boundary-of-boundary 條件 $$B_1B_2=0.$$ 一階 Hodge Laplacian 為 $$\Delta_1=B_1^\mathsf{T}B_1+B_2B_2^\mathsf{T}.$$
拓撲可見性
離散 Hodge theorem 給出 $$\ker\Delta_1\cong H^1,\qquad \dim\ker\Delta_1=b_1=2g$$ （connected closed orientable surface）。這不是 vertex Laplacian 的經驗猜測， 而是直接使用 face incidence 的可驗證拓撲量。

catalogue 中 25 個曲面全部通過 $B_1B_2=0$ 與 $\dim\ker\Delta_1=2g$ 的數值檢查。

8. Spectral clustering 與不對稱性

研究不應只問「eigenvalue 是否與 genus 相關」，而應先指定哪個 operator、哪種對稱破壞、 以及 clustering 的 ground truth：

層級操作可觀察問題
S0固定 Cayley skeleton，只換 face system$L_0$ 不變；$\Delta_1$ 與 face-aware operators 改變
S1改 generator weightsregular group action 仍在，但不同方向的重要性不對稱
S2改個別 edge weights 或刪邊vertex transitivity 破壞，eigenspaces 分裂，clusters 可能局部化

可執行實驗是：對同一 skeleton 的不同 $\mathcal F$，比較 $L_0$、dual graph Laplacian、 face-inflated graph Laplacian 與 $\Delta_1$；再用 eigengap、normalized cut、cluster stability 以及與 face/coset labels 的 adjusted Rand index 評估。這能把「圖看起來分群」改成可重現問題。

9. 三個對外數學問題

  1. Graph genus 與 cellular embedding enumeration：一般 graph genus 決定問題已知困難； 本專題可問 Cayley 對稱是否允許 orbit reduction、canonical labeling 或受限群族分類。
  2. Bounded-genus spectral partitioning：已有理論把 genus 與 spectral cut 品質連結； 本專題可測試 face-aware operator、asymmetry 與 multiway clustering 是否保留這些界。
  3. Cayley-DS 與 cospectral Cayley graphs：哪些有限群可由 Cayley graph spectrum 區分、哪些不同生成集產生 cospectral non-isomorphic graphs，仍有大量分類問題。
