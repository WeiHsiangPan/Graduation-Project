Rotation Systems、離散 Hodge 與 Spectral Clustering

Pan Wei-Hsiang · Department of Mathematics, NYCU

核心問題

Cayley graph $\operatorname{Cay}(G,S)$ 只是一維骨架。加入哪些面， 才得到 closed orientable surface？同一骨架能得到哪些不同曲面？
  • 代數資料：有限群 $G$ 與對稱生成集 $S=S^{-1}$
  • 拓撲資料：face system $\mathcal F$
  • 可重現資料：建構 witness $c$；可選 edge weights $\omega$
本專題的基本單位是 $(G,S,\mathcal F,c,\omega)$，不是只有一張漂亮的圖。

兩種乘法，兩種工作

右乘

$g\to gs_1\to gs_1s_2\to\cdots$

沿生成元走邊；relator 產生 closed walk。

左乘

$\{g,gs\}\mapsto\{hg,hgs\}$

平移整張圖與面；給出 vertex transitivity。

Relator 只產生候選面：仍需檢查 simplicity、dart coverage 與 vertex links。

Rotation system 產生面

Dart $(g,s)$ 表示 $g\to gs$；反向 permutation：

$$\alpha(g,s)=(gs,s^{-1}).$$

在每個頂點選一個離開 darts 的 cyclic order，合成 rotation permutation $\sigma$。

$$\varphi=\sigma\alpha,\qquad \text{faces = cycles of }\varphi.$$

對 connected graph，一個 orientable rotation system 決定 cellular embedding； 從任意 face list 重建時，vertex link 必須是單一圓。

驗證 surface，而不是相信圖形

  1. $S=S^{-1}$ 且 Cayley graph connected
  2. 每個 face 是 simple cycle
  3. 所有 face darts 恰好 partition $G\times S$
  4. 每個 vertex link 是一個 cycle
  5. $\chi=V-E+F=2-2g$
只驗證「每條 edge 左右各有一個面」不夠：vertex 仍可能成為 pinch point。

「所有面系統」為何困難

若 degree $d=|S|$，每個頂點有 $(d-1)!$ 個 cyclic orders；一般候選數約為

$$((d-1)!)^{|G|}.$$

兩種 spectrum：一個看不到面，一個看得到

Vertex Laplacian

$L_0=|S|I-A$

只依賴 $(G,S)$；可由 irreducible representations block-diagonalize。

Hodge 1-Laplacian

$\Delta_1=B_1^\mathsf{T}B_1+B_2B_2^\mathsf{T}$

使用 edge-face incidence；依賴 $\mathcal F$。

$$B_1B_2=0,\qquad \dim\ker\Delta_1=2g.$$

三個真實數學問題

  1. Graph genus / embedding enumeration：Cayley 對稱能否降低一般 genus 問題的複雜度？
  2. Bounded-genus spectral partitioning：face-aware 或不對稱 operator 是否保留 cut guarantees？
  3. Cayley-DS / cospectrality：vertex spectrum 分不開的 Cayley graphs，加入曲面資料後能否區分？

三者分別提供：複雜度背景、既有理論 benchmark、仍活躍的分類問題。
