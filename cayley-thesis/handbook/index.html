Cayley Surface 專題手冊

本專題研究同一個 Cayley graph 骨架如何藉由不同面系統形成不同曲面， 並比較一般圖譜、離散 Hodge 譜與 spectral clustering 能保留哪些代數及拓撲資訊。

目前可重現狀態：25 / 25 通過
10 個有限群、25 個曲面 witness 均已通過連通性、inverse closure、dart 唯一使用、 simple face、單圈 vertex link、Euler genus、鏈複形與 dim ker(Delta_1) = 2g 的檢查。更新日期：2026-07-16。

資料與程式

曲面 catalogue
唯一的 machine-readable source of truth：群、生成元、面系統 witness、genus、face profile 與驗證狀態。
驗證器
在專案根目錄執行 python handbook/verify_examples.py。驗證器會由 catalogue 重建每一個曲面，而不是讀取預先寫死的答案。
建構核心與繪圖
code/surface_systems.py 是群、rotation system、face 與驗證的核心； code/draw.py 是舊版 Plotly 視覺化入口，其 torus 背景只代表顯示座標，不能取代拓撲驗證。

thesis/、progress/ 與 references/ 中的 PDF 保留為歷史材料；數值或狀態若與本頁不同，以 catalogue、驗證器與 README 為準。
