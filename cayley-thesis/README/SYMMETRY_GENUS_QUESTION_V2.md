# 第二版主問題：固定 Cayley 骨架的 genus 與可延伸群對稱

2026-10-22。取代第一版「等價關係整理」作為建議研究主線。此為提案，未完成文獻新穎性確認，亦未執行以下全枚舉。

## 主問題

固定 G=D_n（階為 2n），S={r,r⁻¹,s}，Γ_n=Cay(G,S)。對每個可由 rotation system σ 實現的 genus g，原有左正則 G 作用中，最多有多大的子群能延伸成保留定向與胞腔分解的曲面對稱？

定義 λ_h(x,s)=(hx,s)，以及

H_σ={h∈G : λ_h σ=σ λ_h}。

H_σ 是 G 的子群；因 λ_h 與 edge reversal α 交換，上式保證其作用保留面 cycles 並延伸到曲面。此處只計保留定向的對稱，不是全部 map automorphisms，也不是曲面所有 homeomorphisms。

目標量為

m_n(g)=max{|H_σ| : genus(σ)=g}。

不存在此 genus 時記為不可實現，不把最大值寫成 0。

核心先做 n=4,5,6；n=7,8 是擴充。未商掉的 rotation 數分別為 256、1024、4096，擴充為 16384、65536。計數是候選狀態數，不是執行時間保證。

## 為何超過例子整理

不是再證明同一圖可產生不同曲面，而是求每個 genus 下的最優對稱保留量，並提供達到最大值的 witness 和排除更大值的理由。即使枚舉答案已有文獻，也必須明說是重現；若能提出並證明一個族上的界線，才是更強的理論成果。

不能事先斷言 genus 增加必然降低對稱性。非單調、相同最大值或特殊例外，都可成為應解釋的結果；但若整張表可立即由已知定理推出，就不應把表當主要貢獻。

## 理論切入

三價圖每個頂點只有兩種 cyclic order，用 b:G→{0,1} 記錄。則 H_σ={h:b(hx)=b(x) 對所有 x}。

因此 H≤H_σ 當且僅當 b 在左 H 軌道 Hx 上常值。可先枚舉子群 H，再搜尋僅有 2^[G:H] 個 H-invariant bit patterns，找出指定對稱要求下可達的 genus 集合。這是標準群作用觀察的應用，不宣稱為新演算法。

要分清楚：b 在 H 軌道上常值只保證 H≤H_σ，實際穩定子可能更大。證明 m_n(g) 時要計算實際穩定子，或逐一排除所有更大候選子群。

第一個自行證明的命題是上述等價性；進一步根據數據選一個「某類 H 只能出現哪些 genus」的具體命題，嘗試用 face permutation cycles 證明。不能在尚無數據時承諾一般公式。

## 最小交付

1. n=4,5,6 的完整 m_n(g) 表，各格附 rotation／face witness。
2. 全量計算與 subgroup-invariant 搜尋相互核對。
3. 對最優性的完整有限證書，以及至少一個可手算解釋的排除理由。
4. 分開說明已知定理、自己的有限計算、尚未證明的猜想。

主表採所有 orientable cellular rotations；simple-face 子類另列比較，不混用。現有 validator 若預設 simple faces，需調整使用方式，不能默默把一般 cellular maps 過濾掉。

群作用是研究資料的一部分。任意抽象圖同構可能改變指定 G 作用；若做等價去重，必須同步搬運群作用，或只用保持該作用結構的等價。不能用任意 Aut(Γ) quotient 後假設 |H_σ| 不變。

## 七週與停損

- 第 1 週：查 prism embeddings、Cayley maps、equivariant embeddings、map automorphism groups 文獻；做 n=4 pilot，確認定義與例子。
- 第 2 週：完成 n=4,5,6 的 (genus, |H_σ|) 全量表，提出第一個具體 conjecture。
- 第 3 週：按子群重做搜尋，取得最優性證書；校對方向與 simple-face 範圍。
- 第 4–5 週：集中證明一項數據支持的界線；有餘力才做 n=7,8。
- 第 6–7 週：寫作、重現、圖表與答辯。

第二週是研究判斷點：若問題已有直接完整答案，或數據沒有可解釋結構，據文獻及 pilot 改題，不用擴大數據量掩蓋問題。可評估改研究「指定子群可達 genus 集合」或 simple-face 限制帶來的差異，但必須重新檢查是否同樣已知。

學術新穎性尚待文獻確認；八週內可承諾的是可重現且有最優性驗證的有限研究，不能承諾發現新的普遍定理。
