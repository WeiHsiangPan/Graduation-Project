# 單四面體 36 種貼合：從一個案例讀懂整條流程

本講義使用[完整結果表](results-table.md)中的實際案例。矩陣採本輪程式保存的字典序局部代表元，數值與對應基底可在最新執行目錄的 `cases/<ID>.json` 查到；[latest-run.json](latest-run.json)記錄該目錄。不同程式若選不同基底，矩陣可能不同，整數同調應一致。

## 先讀懂案例編號

固定一個頂點標為 0、1、2、3 的四面體。第一次把面 012 貼到面 013，第二次把面 023 貼到面 123。每次各有六種頂點對應，兩次共有 6 × 6 = 36 案。

`130-231` 的意思是：

| 次數 | 面貼合 | 三個頂點對應 |
|---|---|---|
| 第一次 | 012 → 130 | 0 → 1、1 → 3、2 → 0 |
| 第二次 | 023 → 231 | 0 → 2、2 → 3、3 → 1 |

三元組的順序就是映射，不應把 `130` 排成 `013` 後再解讀。四元排列另將省略的頂點映到對方省略的頂點，便於檢查整個四面體的方向。

## 案例一：013-123，合法且 H₁ = 0

**第一步：合併頂點。** `012→013` 只新增 2 ∼ 3，得到 {0}、{1}、{2,3}。第二次 `023→123` 新增 0 ∼ 1，最後有兩個頂點類：

\[
A=\{0,1\},\qquad B=\{2,3\}.
\]

**第二步：重建頂點附近的小三角形。** 四面體每個角各切出一片 link 三角形，再依面映射貼合它們。兩個頂點類各有兩片三角形；每個 link 的 (V,E,F) = (3,3,2)，故 χ = 2。程式另檢查連通、每個 link 頂點的局部圓圈、可定向性與無邊界，才判定兩個 links 都是球面。

**第三步：分別檢查原邊與整體方向。** 此案沒有原邊反向自識別；兩次完整排列 `0132`、`1023` 都是奇排列，誘導的面貼合與單一四面體的整體方向相容。所有面都已配對，因此通過閉、連通、可定向三維流形判準。[判準來源：Definition 4，第 4 頁](../../references/Fixed%20parameter%20tractable%20algorithms%20in%20combinatorial%20topology.pdf)

**第四步：算整數同調。** 用頂點基底 A、B，邊基底 $a=[01],b=[02],c=[23]$，程式保存：

\[
B_1=\begin{pmatrix}0&-1&0\\0&1&0\end{pmatrix},\qquad
B_2=\begin{pmatrix}0&1\\0&0\\1&0\end{pmatrix},\qquad
B_3=\begin{pmatrix}0\\0\end{pmatrix}.
\]

邊 b 從 A 通到 B，所以它本身不是一維閉鏈；a、c 才生成 $\ker B_1$。而 $B_2$ 的兩欄恰好生成 c、a，因此

\[
H_1=\langle a,c\rangle/\langle c,a\rangle=0.
\]

這個例子提醒我們必須算 $\ker B_1/\operatorname{im}B_2$，不能只取 $B_2$ 的 cokernel；後者會錯把非閉鏈 b 留下。完整結果為

\[
(H_0,H_1,H_2,H_3)=(\mathbb Z,0,0,\mathbb Z).
\]

僅憑這組同調，尚不能替該流形命名。

## 案例二：相同 Ce/Cv，相同最後貼合，為何得到四與五？

比較 `130-231` 與 `301-231`。它們第一次貼合不同，最後一次完全相同。

**第一步：檢查第一次貼合後的邊界。** 兩案都把四個頂點合為同一類，剩下面 023、123。唯一頂點 link 都是圓盤，(V,E,F) = (6,9,4)、χ = 1、一個邊界圈。兩者的標記邊界狀態完全相同：

| Ce 的兩個邊界出現位置 | 方向 |
|---|---|
| 023/02 ↔ 123/13 | 相反 |
| 023/03 ↔ 123/12 | 相反 |
| 023/23 ↔ 123/23 | 相同 |

Cv 則只有一類 {0,1,2,3}。這裡的 Ce/Cv 只記邊界標記及識別關係，沒有存下整個內部貼合歷史。

**第二步：替共同邊界上的圈命名。** 記

\[
x=[03],\qquad y=[13],\qquad z=[23].
\]

Ce 給出 $[02]=-y$、$[12]=-x$。面 023 的邊界滿足 $[23]-[03]+[02]=0$，所以 $z=x+y$；面 123 也給同一關係。邊界同調可用 x、y 作基底。

**第三步：問這兩個邊界圈進入內部後變成什麼。** 兩個部分空間的精確整數同調均為 $(\mathbb Z,\mathbb Z,0,0)$。選各自內部 H₁ 的一個生成元 u，保存的整數計算給出：

| 第一次貼合 | x | y | z = x + y |
|---|---:|---:|---:|
| 012 → 130 | 2u | u | 3u |
| 012 → 301 | u | 2u | 3u |

這張表是邊界到內部同調的包含映射。同樣的邊界圈，在兩個內部代表的倍數不同；這項資訊不在共同 Ce/Cv 裡。完整整數基底、Smith 證書及映射向量見[包含映射證據](boundary-inclusion-witness.json)。圓盤 link 與 H₁ = ℤ 本身不足以證明整個部分空間是實心環面；本推導不需要這項全域識別。

**第四步：施加共同最後貼合。** `023→231` 把邊 02 映到 23，要求 $[02]=[23]$。代入共同邊界關係：

\[
-y=x+y\quad\Longleftrightarrow\quad x+2y=0.
\]

其他邊的識別給出同一關係或恆等式。因此：

- 首貼 130：$x+2y=2u+2u=4u$，完成後 H₁ = ℤ/4。
- 首貼 301：$x+2y=u+4u=5u$，完成後 H₁ = ℤ/5。

**第五步：直接核對完成後的矩陣。** 本輪字典序基底下的實際 $B_2$ 為

\[
B_2^{130-231}=\begin{pmatrix}-2&2\\-1&-1\end{pmatrix},\qquad
B_2^{301-231}=\begin{pmatrix}1&2\\2&-1\end{pmatrix}.
\]

第一個矩陣的邊基底為 [01]、[03]，第二個為 [01]、[02]；兩者 $B_1=0$、$B_3=0$。其行列式分別為 4、−5，所有元素的最大公因數均為一，因此 Smith 因子分別是 (1,4)、(1,5)，與上述包含映射推導一致。兩案都通過球面 link 與邊方向檢查，完整同調分別為

\[
(\mathbb Z,\mathbb Z/4,0,\mathbb Z),\qquad
(\mathbb Z,\mathbb Z/5,0,\mathbb Z).
\]

這是「壓縮狀態忘記了哪些資訊」的具體有限證據。它沒有推翻論文的合法性更新方法：兩案的合法性確實都通過，差別發生在該狀態原本不負責保留的整數同調。

## 案例三：103-132，球面 links 仍然不夠

第一次 `012→103` 把 0 → 1、1 → 0，所以原邊 01 直接映成 10，反向識別到自身。第二次 `023→132` 又把原邊 23 映成 32。任一項已足以拒絕。

最後的兩個頂點 links 都算出 (V,E,F) = (3,3,2)，也都通過球面檢查；這仍不能消除原邊中點附近的非法識別。程式另記錄整體不可定向，拒絕碼為 `REVERSED_SELF_EDGE`、`AMBIENT_NONORIENTABLE`。因此，「球面 link」與「沒有反向自識別邊」必須分開檢查。

## 案例四：031-213，邊方向通過卻仍須拒絕

此案沒有邊反向自識別，但四個頂點合成同一類，唯一 link 的資料為

\[
(V,E,F)=(2,6,4),\quad\chi=0,\quad b=0.
\]

局部曲面與連通檢查通過，但方向方程不一致，故 link 不可定向。閉、連通、不可定向且 χ = 0 的曲面是 Klein bottle，並非球面。程式以 `NONSPHERICAL_VERTEX_LINK` 拒絕；整個貼合也不可定向。

這個例子說明 Euler characteristic 為零尚不足以判斷曲面類型，方向資訊也必須保存；而「沒有反向自識別邊」本身仍不足以保證三維流形。
