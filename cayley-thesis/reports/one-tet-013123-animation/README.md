[Manim 動畫](OneTet013123.mp4)；[八格圖解](storyboard.png)；[逐階段精確資料](stages.json)。

固定面配對：012→013、023→123。圖中分開畫的面仍屬於同一四面體，箭頭表示頂點識別，不是模擬無交叉的物理折疊。

1. 初始：四個頂點類，四張未配對面；各角link為三角形圓盤。
2. 第一次012→013：0→0、1→1、2→3，得到{0},{1},{2,3}；剩023、123。Cv保存這三類邊界頂點；Ce保存三對邊界邊及方向。
3. 第二次023→123：0→1、2→2、3→3，得到A={0,1}、B={2,3}。所有面用完，Ce與Cv均空；實際頂點並未消失。
4. A的link由角0、角1的小三角形組成；B由角2、角3組成。各有V=3,E=3,F=2，另通過局部曲面、方向、連通與無邊界檢查，因此均為球面。球面圖示為拓撲示意，不是三角形線性嵌入的精確形狀。
5. 面配對圖只有一個節點t0與兩個環；它不記頂點排列，也不是貼合空間的1-skeleton。
6. 本例通過反向邊與整體可定向性檢查，是廣義三維三角剖分；同調(Z,0,0,Z)本身不作流形名稱識別。
