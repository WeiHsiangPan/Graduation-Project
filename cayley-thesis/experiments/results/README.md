兩輪各使用 D4、Q8、S4、seed 0/1/2、關係最大長度 6、反例搜尋長度 6。每輪完成 648 次目標求解（三組方法），全部距離符合 BFS。每輪另有兩個 surface 因沒有長度範圍內的面關係而記錄 skipped。

兩輪的 ordinary 與 faces 在總生成節點數上均持平，**目前沒有證據支持貼面優於一般短關係**。這只針對此實驗範圍，不否定其他模型。

S4 的取消逆操作基準共生成 1261 個節點；完整預算的兩種關係方法均為 1003；限制預算均為 1090。這顯示關係剪枝可以改善這個搜尋器，但不顯示面來源有額外優勢。完整成本還要看規則掃描與前處理，微小執行時間不適合推論穩定加速比。

反例保存在每個 case 的 `methods.<name>.counterexample`，也以生成元標籤列在 summary。例：D4 只做相鄰逆操作消去時，`r r r` 不可化簡，但最短代表為 `r^-1`。

每輪 `verification.json` 記錄獨立檢查狀態及結果檔雜湊。它是 Python 驗證紀錄，尚非 Lean 形式化證明。
