Ce/Cv 加入邊界同調包含映射：本週新增實作

本輪實作候選狀態 `C+ = (Ce,Cv,H1(M),i1)`，其中 `i1:H1(∂M;Z)→H1(M;Z)`。邊界標記保持固定；內部 H1 為 Z 時，生成元同時換號視為相同。邊界基底由 Ce/Cv 決定，不使用最後貼合或最後同調選取。

主要結果：

| 項目 | Ce/Cv | 加入 H1 包含映射 |
|---|---:|---:|
| 三種合法中間歷史的狀態組數 | 2 | 3 |
| 不同歷史、同狀態、同末貼合比較 | 6 | 0 |
| 其中兩案均通過閉流形判準 | 3 | 0 |
| 最終整數同調不同的反例 | 2 | 0 |

兩個舊反例為 `130-231` vs `301-231`、`130-312` vs `301-312`。130 與 301 的邊界同調基底均由程式取為 ([03],[23])，其包含映射經內部生成元換號規範後分別為 [2,3]、[1,3]，因此不再合併。以較熟悉的 x=[03]、y=[13] 表達，就是 [2,1]、[1,2]。

零個剩餘反例的解讀有明確限制：三種合法歷史全部被拆開，故沒有任何不同歷史仍共享增強狀態。本輪證明這項資訊能分開已知反例；沒有測出保留非平凡狀態合併的壓縮效果，也不能以此證明一般充分性。

額外實作了只讀取邊界資料、同調映射及最後面貼合的 H1 預測器。它不接收首次貼合、內部鏈矩陣或完成後真值。合法中間歷史的 18 次完成嘗試中，9 次因邊界商的邊反向自識別拒絕；其餘 9 次預測全部符合完整歷史算出的 H1。預測會保存邊界商 Q、商映射 q、同調群與商群關係矩陣的整數證書。

原始六種歷史及全部 36 案均保留。031、103、310 的首次貼合已不符合本輪可定向流形前綴要求，因此有 18 案在增強狀態實驗中明確標為排除；它們未被當作成功預測。所有 90 個相同末貼合的不同歷史配對都保存，其中 18 個配對的兩邊皆屬合法前綴。

重跑（於專案根目錄）：

```powershell
python cayley-thesis/experiments/enhanced_boundary_states.py
python cayley-thesis/experiments/verify_enhanced_boundary.py --run <新結果目錄>
python -m unittest discover -s cayley-thesis/experiments -p "test_*.py"
```

主實驗與檢查器只需 Python 標準函式庫。每次建立新時間戳資料夾；`run-status.json` 會區分未完成、尚未核對與 PASS。正式發布位置只有核對通過後才更新，開發中未完成或未核對的輪次不作結論依據。

原 36 案使用副本重新核對，舊結果與舊交付雜湊不被改寫。每輪包含 histories/ 六個狀態與證書、transitions/ 36 次貼合及預測、comparisons/ 90 個比較、原資料重新核對副本及新獨立驗證結果。

證據與範圍：

- 邊界鏈複形完全從 Ce/Cv 與邊界面標記重建；包含映射驗證 Bk Jk = J(k-1) ∂Bk。
- H1 以整數 kernel/image 與 Smith 證書計算；另一套程式使用獨立組合重建和精確小行列式核對。
- 狀態相等只涵蓋本輪內部 H1=0 或 Z 的情況；尚無任意秩與 torsion 的映射等價規範形。
- 預測器使用連通 CW 邊界貼合下的 Mayer–Vietoris 推導，僅預測 H1，不取代局部流形合法性檢查。[Hatcher，Algebraic Topology，§2.2，尤其印刷頁 152；Proposition 0.18](https://pi.math.cornell.edu/~hatcher/AT/AT.pdf)
- 尚未實作一般 treewidth 動態規劃、一般同調增強狀態更新或 Lean 證明；本輪也未證明狀態或搜尋量的漸近改善。
